# Brain.exe

A minimalist, distraction-free productivity system designed for focused work. Brain.exe avoids gamification anxiety (such as streaks, badges, and constant notifications) to provide a quiet, priority-focused interface.

## Live Website
The project landing page is live at [brainexe-web.vercel.app](https://brainexe-web.vercel.app).

## Key Features
- **Minimalist Interface**: Soft typography and layouts designed to minimize visual noise and maximize focus.
- **Focus Dashboard**: Quick access to current focus areas, task priorities, and associated notes.
- **Task Deconstruction**: Breaks down larger, vague goals into clear, actionable steps.
- **Offline Capabilities**: Saves data locally and synchronizes once back online.

## Structure & Architecture
- `index.html`: Main landing page introducing the Brain.exe workflow and interface elements.
- `Dashboard.dc.html`: The core user interface for task management, focus timers, and notes.
- `support.js`: Core runtime JavaScript handling offline storage, component rendering, and application logic.
